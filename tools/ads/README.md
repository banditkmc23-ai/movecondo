# โฆษณาบน MoveCondo (ลงเอง) · Self-managed ads

โฆษณาทั้งหมดอยู่ในไฟล์เดียว: `ads/ads.json` ส่วนรูปเก็บไว้ที่ `ads/img/`

## ช่องโฆษณาว่าง
ทุกตำแหน่งแสดงบนเว็บจริงเสมอ ถ้าตำแหน่งไหนยังไม่มีโฆษณาจริงที่ `active` และอยู่ในช่วงวันที่ จะขึ้นกล่อง **"พื้นที่โฆษณา · สนใจลงโฆษณา ติดต่อเรา"** (EN: "Ad space · Advertise with us") ลิงก์ไปหน้า Partner แทน
พอเพิ่มโฆษณาจริงให้ตำแหน่งนั้น กล่องนี้จะถูกแทนที่เอง คลิกกล่องนี้นับในสถิติเป็นคำค้น `ad:placeholder`

## ลงโฆษณาใหม่ (4 ขั้น)
1. เตรียมรูปแนวนอน สัดส่วน **2:1** (แนะนำ 1200×600 px, ไฟล์ .webp หรือ .jpg ไม่เกิน ~200 KB) แล้ววางใน `ads/img/`
   - รูปห้ามมีหน้าคน เบอร์โทร LINE ID หรือข้อมูลเจ้าของห้อง
2. เปิด `ads/ads.json` แล้วเพิ่มโฆษณา 1 ก้อนในรายการ `"ads"` เช่น

```json
{
  "id": "promo-dec-2026",
  "active": true,
  "slots": ["home", "room"],
  "image": "img/promo-dec-2026.webp",
  "title": { "th": "ย้ายเข้าเดือนธันวาคม รับส่วนลด", "en": "Move in this December and save" },
  "text":  { "th": "ข้อความสั้น 1–2 บรรทัด", "en": "One or two short lines" },
  "link": "https://example.com/promo",
  "cta":   { "th": "ดูรายละเอียด", "en": "Learn more" },
  "start": "2026-12-01",
  "end":   "2026-12-31",
  "weight": 1
}
```

3. ตรวจก่อนขึ้นจริง: เปิดเว็บแล้วต่อท้ายลิงก์ด้วย `?adpreview=1` (ปิดด้วย `?adpreview=0`)
4. commit + push ขึ้น GitHub แล้วรอ ~1–10 นาที โฆษณาจะขึ้นเอง ไม่ต้องแก้ไฟล์อื่น

## ความหมายของแต่ละช่อง
| ช่อง | ความหมาย |
|---|---|
| `id` | ชื่อเรียกโฆษณา ภาษาอังกฤษตัวเล็ก/ตัวเลข/ขีด ห้ามซ้ำ (ใช้นับคลิกในสถิติ เป็นคำค้น `ad:<id>`) |
| `active` | `true` = แสดง, `false` = ซ่อน (ปิดชั่วคราวได้ทันที) |
| `slots` | ตำแหน่งที่แสดง: `home` (หน้าแรก คั่นระหว่างแถวหมวด 2 จุด), `room` (หน้าห้อง ใต้กล่องรายละเอียด), `area` (หน้าทำเล หลังห้องที่ 4), `project` (หน้าโครงการ หลังห้องที่ 4 หรือใต้รายการห้อง) |
| `image` | รูป อยู่ใต้ `ads/` เช่น `img/xxx.webp` |
| `title`, `text`, `cta` | ข้อความไทย/อังกฤษ (`cta` = ปุ่ม ไม่ใส่ก็ได้; `text` ไม่ใส่ก็ได้) |
| `link` | ลิงก์ปลายทาง (เปิดแท็บใหม่ ติด `rel="sponsored"` ให้อัตโนมัติ) |
| `start`, `end` | วันเริ่ม/วันสุดท้ายที่แสดง (รูปแบบ ปี-เดือน-วัน ค.ศ. ตามเวลาไทย) |
| `weight` | ถ้ามีหลายโฆษณาในตำแหน่งเดียวกัน จะสุ่มสลับกัน ตัวเลขมาก = ขึ้นบ่อยกว่า (ค่าเริ่มต้น 1) |
| `example` | `true` = โฆษณาตัวอย่าง จะไม่แสดงบนเว็บจริงเลย เห็นเฉพาะตอน `?adpreview=1` |

## กติกา
- ไม่มีโฆษณาที่ active ในตำแหน่งไหน = ตำแหน่งนั้นไม่แสดงอะไรเลย (ไม่มีกล่องว่าง)
- ทุกโฆษณามีป้าย "โฆษณา · Ad" ให้อัตโนมัติ
- ลบโฆษณาตัวอย่าง (`example-*`) และรูปใน `ads/img/example-*.webp` ได้เมื่อมีโฆษณาจริงแล้ว
- สถิติ: นับเฉพาะ "คลิก" (เก็บเป็นคำค้น `ad:<id>` ในหน้าสถิติ) ยังไม่นับการเห็นโฆษณา เพราะระบบสถิติยังไม่มีประเภท event สำหรับโฆษณา (ต้องเพิ่ม `ad_view` / `ad_click` ในฐานข้อมูลถ้าต้องการนับแบบแยก)
